# IdeaFlow · 灵感表

**From spark to shipped.** 一个「先捕捉、后深化、再推进」的灵感管理 Web 应用：像微软 To Do 一样零成本速记，用构思框架把灵感展开成方案，用五态项目管线一路推进到落地。

> IdeaFlow (灵感表) is a local-first idea manager: capture in one keystroke, flesh out with a thinking framework, then drive it through a 5-stage pipeline — no account, no build, no server.

![版本](https://img.shields.io/badge/version-v1.0-blue) ![技术栈](https://img.shields.io/badge/stack-HTML%2FCSS%2FJS-orange) ![依赖](https://img.shields.io/badge/dependencies-0-brightgreen) ![存储](https://img.shields.io/badge/storage-localStorage-lightgrey)

## 快速开始

三种方式任选，无需 npm、无需构建、无需服务器：

```bash
# 方式一：直接打开
双击 index.html

# 方式二：起个本地服务（推荐，避免个别浏览器对 file:// 的限制）
python -m http.server 8000
# 然后访问 http://localhost:8000

# 方式三：部署到 GitHub Pages
# 仓库 Settings → Pages → Source 选 main 分支根目录 → Save
```

打开即用，首次访问会自动灌入 10 条示例灵感 + 4 个分组，可直接体验全流程。

## 它解决什么问题

| 痛点 | IdeaFlow 的做法 |
| --- | --- |
| 灵感在碎片时间出现，来不及记 | 页面加载即聚焦输入框，**回车 = 保存**（1 次交互），可连续录入 |
| 待办工具太浅，装不下灵感的展开与推敲 | 点击条目右侧滑出详情面板，用**构思框架**把一句话变成方案 |
| 想法确认要做后，计划书/任务/进度散落各处 | 导入 `.md` 计划书，自动解析成**可勾选任务树**，进度自动汇总 |
| 放弃的想法不想删，删了又后悔 | 「已废弃」留档可恢复；删除也有 5 秒撤销 |

## 核心功能

### 模块 A · 灵感速记
- **极速添加**：回车即存，连续录入不中断；分组视图下自动归入当前分组
- **列表操作**：圆圈勾选 = 完结归档、星标标记重要、行内改名、右键移动分组
- **分组管理**：内联新建、双击重命名、右键删除（删组时灵感自动移入收集箱）
- **智能视图**：全部 / 重要 / 五态视图共 7 个，角标计数实时更新
- **排序**：创建时间 / 更新时间 / 手动拖拽，三档循环切换
- **删除撤销**：底部 toast 5 秒内可撤销

### 模块 B · 灵感深化（二级界面）
- **详情面板**：点击条目右侧滑出（0.3s 过渡），与列表双向同步
- **自动保存**：所有输入框停顿 500ms 即落盘，失焦立即保存，全程没有「保存按钮」
- **构思框架**：核心想法 / 为什么值得做 / 步骤清单 / 风险疑问；步骤可勾选、双击编辑、拖拽排序，进度徽标回写列表
- **五态流转**：新灵感 → 待推进 → 进行中 → 已完结 / 已废弃，列表、侧栏角标、面板三处同步
- **标签与链接**：全库标签智能推荐；参考链接粘贴即记录

### 模块 C · 项目管线
- **新灵感 · 联网调研**：必应 / 百度 / GitHub / 知乎一键检索入口，记录参考链接与查重结论（重复 / 近似 / 空白）
- **待推进 · 任务书**：目标 / 范围 / 里程碑 / 验收标准四字段，可一键从构思框架生成初稿（只填空缺项）
- **进行中 · MD 计划导入**：本地 FileReader 解析，**文件不上传**；识别 `#`~`####` 标题与 `- [ ]` / `- [x]` / `*` / `+` / `1.` 任务，生成可折叠可勾选任务树
- **进度跟踪**：勾选自动汇总百分比，同步进度条 / 面板 / 列表三处；重新导入按「标题 + 任务文本」合并，**已勾选状态优先保留**
- **批量流转**：工具栏进入批量模式，多选后一键流转状态

### 工程与体验
- **全局搜索**：跨标题、备注、框架四区块、步骤、任务书、计划任务、标签、链接、完结小结、废弃原因；命中处黄色高亮
- **JSON 备份**：导出 `灵感表备份-20261010-0915.json`；导入可选**覆盖**（整份还原）或**合并**（按 id 去重，更新时间新的优先）
- **明暗双主题**：跟随系统 + 手动切换；每个分组一个主题色，换组换色
- **响应式**：≤900px 侧栏抽屉化，≤640px 面板全宽，375px 窄屏可用

## 快捷键

| 按键 | 作用 |
| --- | --- |
| `/` 或 `Ctrl + K` | 聚焦搜索 |
| `Ctrl + N` | 新建灵感（聚焦速记框） |
| `Ctrl + E` | 导出 JSON 备份 |
| `Esc` | 逐层退出：清空搜索 → 收起抽屉 → 退出批量 → 关闭面板 |

## 数据与隐私

- 所有数据存放在浏览器 `localStorage`（key：`idea-board-store-v1`），**不上传任何服务器**
- 导入的 `.md` 计划书通过 FileReader 在本地解析，文件内容不会离开本机
- 备份导出 / 导入为纯本地文件操作
- 清除浏览器数据会丢失记录，建议定期用「导出备份」保存 JSON

**安全处理**：所有用户输入渲染前转义；外链走 URL 白名单（仅 http/https/mailto），`javascript:` / `data:` 伪协议一律拦截。
